# CodeQuest offline APK
1. Create a new GitHub repo, upload everything in this folder (keep the .github folder).
2. Repo > Actions > "Build CodeQuest APK" > Run workflow.
3. When it finishes, download the "CodeQuest-apk" artifact, unzip, copy app-debug.apk to the Pixel 5.
4. Open it on the phone and allow "install unknown apps" for your file manager/browser.
Before reinstalling/updating, use the in-app "save code" export: a different signing key means uninstall, which wipes progress.
